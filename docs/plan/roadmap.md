## 1. 지금 어디까지 왔나

**핵심 기능은 완성됐다.** Spotify 재생 곡의 싱크 가사가 잠금화면 카드에 표시되고, 잠긴 상태에서도 계속 갱신된다.

| 영역 | 상태 | 비고 |

| 백그라운드 유지 (위치 추적) | ✅ | 재생 중일 때만 켜짐, 정지 3분 후 꺼짐 |
| Spotify 연동 (Web API, 1초 폴링) | ✅ | 88분 테스트, 한도 초과 없음 |

### ✅ P6. 일상 사용 개선 — 006·007 완료
**✅ 006 (완료): 앱을 열고 버튼 누르고 로그 보는 수고 없애기**
1. **앱 열면 자동 시작**: 준비 상태가 모두 ✅이면 앱을 열기만 해도 추적 시작. 버튼은 [정지]만
2. **앱 종료 후 카드 이어받기**: 지금은 앱이 새로 시작될 때 기존 카드를 모두 종료함 → iOS가 앱을 종료한 경우 카드 ▶︎가 동작하지 않음. 기존 카드를 이어받아 ▶︎로 바로 재개 (001 보고서 질문 1의 (b))
3. **메인 화면 정리**: 메인에는 준비 상태 · 현재 재생 · 싱크 보정 · 저장된 가사 · [정지]만. **로그 목록 · [전체 복사] · 배터리 측정 · "한 번 조회해 보기"는 [개발자 메뉴]로** (로그 기록 자체는 계속)
4. **단축어 자동화 (실험 포함)**: 앱이 단축어 동작 "가사 추적 시작"(App Intent)을 제공 → 사용자가 단축어 자동화로 "Spotify를 열 때"(필요하면 "블루투스 이어폰 연결 시"도) 즉시 실행
   - iOS는 다른 앱의 재생 시작을 알려 주지 않으므로 Spotify 재생 자체로 자동 실행은 불가 → 이 방식이 대안
   - 확인할 것: 뒤에서 실행된 인텐트가 **Live Activity를 새로 시작**하고 위치 추적을 켤 수 있는지. 안 되면 앱을 잠깐 열었다 돌아가는 방식으로 변경
   - 한계: Spotify를 열지 않고 잠금화면·이어폰 버튼만으로 재생하면 "Spotify 열 때" 조건은 작동 안 함

**007 (지시서 작성됨 `tasks/007-playback-display-polish.md`, 002 대체): 재생·표시 다듬기**

- 참고: 2026-10-26 사용자 영상에서 Dynamic Lyrics도 오래 멈추면 카드가 멈추고 "클릭하여 Spotify에 다시 연결" 안내 → 탭하면 Spotify 앱이 열리고 가사 재개. SDK 사용으로 추정

### ⚪ P4. Live Activity 수명 제한 대비 (우선순위 최하위)
- iOS는 Live Activity를 **최대 8시간** 뒤 종료 (잠금화면에는 최대 12시간까지 남음)
- 하루 종일 음악을 틀어 두면 카드가 사라질 수 있음
- 계획: 시작 후 7시간 30분쯤 지나면 **카드를 끝내고 새로 시작** (곡 변경 시점에 맞추면 자연스러움)
- 먼저 할 일: 실제로 8시간 후 사라지는지 확인 (장시간 재생 테스트 1회)

- 무료 계정이라 Xcode 설치본은 7일 뒤 실행되지 않음 → **만료 전에 Xcode에서 ▶︎ 한 번** (덮어쓰기라 로그인·권한·저장된 가사 유지)
