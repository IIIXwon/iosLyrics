### ✅ P6. 일상 사용 개선 — 006·007 완료
**006: 앱을 열고 버튼 누르고 로그 보는 수고 없애기**
1. **앱 열면 자동 시작**: 준비 상태가 모두 ✅이면 앱을 열기만 해도 추적 시작. 버튼은 [정지]만
2. **앱 종료 후 카드 이어받기**: iOS가 앱을 종료해도 기존 카드를 이어받아 ▶︎로 바로 재개
3. **메인 화면 정리**: 메인에는 준비 상태 · 현재 재생 · 싱크 보정 · 저장된 가사 · [정지]만. 로그 · [전체 복사] · 배터리 측정 · "한 번 조회해 보기"는 [개발자 메뉴]로
4. **단축어 자동화**: 단축어 동작 "가사 추적 시작"(App Intent)을 "Spotify를 열 때" 자동화로 실행

   - 한계: Spotify를 열지 않고 잠금화면·이어폰 버튼만으로 재생하면 작동 안 함

**007 (002 대체): 재생·표시 다듬기**
