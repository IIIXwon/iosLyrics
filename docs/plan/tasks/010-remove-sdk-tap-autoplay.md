## 할 일

### A. SDK 완전 제거
1. **Swift 패키지 `ios-sdk`(`SpotifyiOS`) 제거** — 프로젝트의 패키지 참조와 앱 타깃의 Frameworks 연결 모두. Xcode 도구로 못 하면 보고서에 **사용자 클릭 경로** (예: 프로젝트 → Package Dependencies → `ios-sdk` 선택 → −)
2. `LiveLyricsExperiment/SpotifyRemoteService.swift` 삭제
3. 호출부 정리: `ContentView`(앱 화면 연결 시도, 개발자 메뉴 "SDK 연결 실험" 구역·스위치·[Spotify 앱으로 SDK 인증] 버튼), `ExperimentController`(▶︎·단축어·`didUpdate`의 연결 시도, Web API 비교 기록), 그 밖에 `🛰` 로그 전부
4. SDK 실험 스위치 값 등 SDK용 `UserDefaults` 키는 삭제 처리 (남아 있어도 읽지 않게)
5. `SpotifyConfig.scopes`에서 **`app-remote-control` 제거**. 권한이 줄어드는 변경이라 **재로그인을 요구하지 않도록** `needsRelogin` 판단을 확인 (필요한 권한이 기록된 권한의 부분집합이면 OK)
6. **유지**: Info.plist `CFBundleURLTypes`(livelyrics)와 `LSApplicationQueriesSchemes`(spotify) — 카드 탭으로 Spotify를 열 때 씀
7. 빌드 후 `SpotifyiOS`·`SPTAppRemote`·`🛰` 검색 결과 0

### B. 카드 탭 → Spotify 열기 → 자동 재생
1. 카드 탭(`open-spotify`)으로 Spotify를 연 직후, 우리 앱이 뒤에서 **2초마다 기기 목록(`GET /me/player/devices`)을 확인, 최대 20초**
   - 시작 전에 한도 차단 중이면 아무것도 하지 않음 (008 규칙)
   - 이미 재생 중으로 확인되면(폴링 또는 기기 목록의 활성 기기) **재생 요청을 보내지 않고 대기 종료**
2. 기억한 기기(`lastDevice`) 또는 `Smartphone` 기기가 목록에 나타나면 **그 기기로 재생 요청 1번** (`play(deviceID:)`, 404면 재생 이전 1회까지 — 기존 순서)
3. 재생 요청 뒤 즉시 1회 조회 → 카드·가사 갱신. 위치 추적이 꺼져 있었다면 켬 (기존 재개 흐름 재사용)
4. 20초 안에 기기가 안 나타나면 중단 (사용자가 Spotify에서 직접 재생하면 기존 폴링이 따라감)
5. 대기 도중 사용자가 ▶︎를 누르거나 다시 카드를 탭하면 **새 대기를 만들지 않고** 기존 대기를 이어감 (중복 방지)
6. 로그: `🔗 Spotify 열림 → 연결 대기 (최대 20초)` / `🔗 기기 나타남 (N초) → 재생 요청` / `🔗 이미 재생 중 → 대기 종료` / `🔗 20초 동안 기기 없음 → 대기 종료`
- 호출 수: 대기 1번당 기기 목록 최대 10회 + 재생 1회 (008 기록에 포함)

### D. 반복되는 단순 로그 제거 (2026-10-27 추가)
정상 동작 중에 계속 쌓이기만 하는 로그를 없애 개발자 메뉴 로그를 문제 확인용으로만 남긴다.

**지울 것 (호출 자체를 삭제)**
| 로그 | 이유 |
|---|---|
| `💓 조회 #N · 앱 상태 · 위치 ON/OFF` (10회마다) | 정상 폴링 확인용. 아래 `💓 조회 재개`가 중단 여부를 대신 알려 줌 |
| `🪪 카드 갱신 #N — 가사 줄 변경` | 가장 많이 쌓임 (줄마다). **이유가 "가사 줄 변경"인 경우만** 기록하지 않음 |
| `📍 위치 수신 #N` (처음·20회마다) | 위치 추적 시작·정지·실패 로그로 충분 |

**남길 것 (디버깅에 필요)**
- `💓 조회 재개 — N만에` (앱 중단 감지), `⏹ 정지` 요약(조회·카드 갱신 횟수 집계는 계속)
- `🪪 카드 갱신` 중 가사 줄 변경을 **제외한** 이유들 (처음·곡 변경·재생·일시정지·안내·시간 보정 등)
- 곡 변경·일시정지·위치 이동·가사 검색/저장·▶︎·단축어·위치 추적 시작/정지·권한·한도·오류(⚠️ ❌ ⛔️)·앱 상태 전환(📱)·배터리(🔋)
- 판단이 애매하면 남기고 보고서에 적기
