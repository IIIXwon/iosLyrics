# 004 — 준비 상태 화면 (권한 안내)

상태: 완료

> 작성: Claude 앱 (계획 담당) · Xcode Agent는 **읽기만**
> 작성일: 2026-10-26 · 로드맵 P2

## 목적
이 앱은 설정이 하나만 빠져도 **조용히 안 된다** (위치 권한이 꺼지면 잠금화면 가사가 멈추고, 실시간 현황이 꺼지면 카드가 안 뜸).
앱 첫 화면 맨 위에 **"준비 상태"**를 두어, 무엇이 빠졌는지와 고치는 방법(설정으로 바로 가기)을 보여 준다.
지금 흩어져 있는 위치 권한 구역·재로그인 안내를 여기로 모은다.

## 할 일
1. **확인 항목 4개** (각각 ✅/❌ + 문제일 때 이유 한 줄 + 해결 버튼)

| 항목 | 확인 방법 | ❌일 때 문구 | 버튼 |
|---|---|---|---|
| Spotify 로그인 | 로그인 여부, `needsRelogin`, Client ID 설정 여부 | "로그인이 필요해요" / "권한이 추가돼서 다시 로그인해야 해요" | 로그인 (기존 동작) |
| 위치 서비스 (기기 전체) | `CLLocationManager.locationServicesEnabled()` | "아이폰의 위치 서비스가 꺼져 있어요" | 설정 열기 + 경로 안내 "설정 → 개인정보 보호 및 보안 → 위치 서비스" |
| 위치 권한 (이 앱) | 미정 / 거부·제한 / 앱 사용 중·항상 | 미정: "위치 권한을 허용해 주세요" · 거부: "꺼져 있으면 잠금화면 가사가 몇 초 뒤 멈춰요" | 미정: 권한 요청 · 거부: 설정 열기 |
| 실시간 현황 | `ActivityAuthorizationInfo().areActivitiesEnabled` | "꺼져 있으면 잠금화면 카드가 뜨지 않아요" | 설정 열기 |

   - "앱 사용 중"이면 ✅ (001에서 충분함을 확인). **"항상 허용"은 요구하지 않는다**
   - 정확한 위치 여부는 확인하지 않는다 (대략적 위치로 충분)
2. **표시 방식**
   - 전부 ✅ → "✅ 준비 완료" 한 줄만 (눌러서 펼치면 4개 항목 보기)
   - 하나라도 ❌ → 자동으로 펼쳐서 ❌ 항목을 위에, 주황/빨강 강조
   - "설정 열기"는 `UIApplication.openSettingsURLString`
3. **자동 갱신**
   - 앱이 화면으로 돌아올 때(`scenePhase == .active`), 위치 권한 변경 알림, 실시간 현황 변경(`ActivityAuthorizationInfo().activityEnablementUpdates`)에 맞춰 다시 확인
4. **시작 버튼과 연결**
   - ❌가 있으면 [잠금화면 추적 시작] 아래에 "준비 상태를 먼저 확인해 주세요" 한 줄. 버튼을 막지는 않는다 (기존 `start()`의 확인 로직 유지)
5. **정리**
   - 기존 "위치 권한" 구역과 **"위치 '항상 허용' 요청" 버튼은 화면에서 제거** (준비 상태로 대체). `LocationKeepAlive.requestAlways()` 함수는 남겨 둠
   - 기존 Spotify 구역의 재로그인 안내는 준비 상태와 중복되지 않게 정리 (로그인·로그아웃 버튼은 유지)
6. **로그**: 준비 상태가 바뀔 때만 한 줄 (예: `🧭 준비 상태: 위치 권한 ❌ → ✅`)

## 사용자가 아이폰에서 확인할 것
1. 평소 상태: 맨 위에 "✅ 준비 완료" 한 줄만 보이는지
2. **실시간 현황 끄기**: 설정 → LiveLyricsExperiment → 실시간 현황 끄기 → 앱으로 돌아오면 ❌로 바뀌고 [설정 열기]로 바로 가는지 → 다시 켜고 돌아오면 ✅
3. **위치 권한 끄기**: 설정 → 앱 → 위치 → "안 함" → 앱 복귀 시 ❌ → [설정 열기]로 "앱을 사용하는 동안"으로 되돌리면 ✅
4. (선택) 위치 서비스 전체 끄기 → ❌와 경로 안내가 맞는지 → 다시 켜기
5. 화면이 이전보다 복잡해지지 않았는지 (위치 권한 구역이 사라졌는지)
