# 006 — 일상 사용 개선 (자동 시작 · 카드 이어받기 · 화면 정리 · 단축어)

상태: 완료

> 작성: Claude 앱 (계획 담당) · Xcode Agent는 **읽기만**
> 작성일: 2026-10-26 · 로드맵 P6

## 목적
지금은 매번 앱을 열어 [잠금화면 추적 시작]을 눌러야 하고, iOS가 앱을 종료하면 카드 ▶︎도 듣지 않으며, 메인 화면에 로그가 계속 쌓인다.
→ **앱을 열기만 하면 동작**, **앱이 종료돼도 카드로 복구**, **메인 화면은 사용자용으로만**, **Spotify를 열 때 단축어로 자동 시작**을 목표로 한다.

## 할 일

### 1. 앱 열면 자동 시작
- 앱이 화면으로 올 때(`scenePhase == .active`, 처음 실행 포함) **준비 상태가 모두 ✅이고 추적 중이 아니면 자동으로 `start()`**
- 단, 사용자가 [정지]를 눌렀다면 자동 시작하지 않는다. 이 "사용자가 정지함" 상태는 `UserDefaults`에 저장 → 사용자가 [시작]을 다시 누르면 해제
- 버튼: 추적 중이면 [정지], 정지 상태면 [시작] (문구에서 "잠금화면 추적" 제거해 짧게)
- 로그: `🚀 자동 시작 (앱 열림)` / `⏸ 자동 시작 안 함 — 사용자가 정지해 둠`

### 2. 앱이 종료된 뒤 카드 이어받기
- 지금은 컨트롤러 `init`에서 기존 Live Activity를 **모두 종료**한다 → 바꾼다
- 앱이 새로 시작될 때 기존 카드가 있으면:
  - 가장 최근 것 1개를 **이어받아** `activity`로 쓰고 추적 상태로 복귀(위치 추적·폴링 재개), 나머지는 종료
  - 이어받은 카드가 있으면 1번의 자동 시작은 새 카드를 만들지 않고 이어받은 카드를 사용
- **카드 ▶︎로 앱이 새로 시작된 경우**(인텐트가 앱을 깨움): 이어받기 → 001의 `resumeFromCard()` 흐름 그대로 진행. 지금처럼 "추적이 꺼져 있어요" 로그만 남기고 끝나면 안 됨
- 사용자가 [정지] 상태로 둔 뒤 남아 있는 카드는 없어야 함 (정지 때 카드 종료는 기존대로)
- 로그: `♻️ 기존 카드 이어받음 (N개 중 1개, 나머지 종료)`

### 3. 메인 화면 정리 + 개발자 메뉴
- **메인 화면에 남길 것**: 준비 상태 · Spotify(로그인/로그아웃) · 현재 재생([가사 다시 찾기] 포함) · 싱크 보정 · 저장된 가사 · [시작]/[정지]
- **메인 화면 맨 아래 [개발자 메뉴]** (작은 글씨 링크) → 새 화면으로 옮길 것:
  - 로그 목록과 [전체 복사]
  - 배터리 측정 기록
  - "한 번 조회해 보기"
  - 조회 간격 선택이 메인에 있다면 이것도 개발자 메뉴로
- 로그 **기록은 계속**한다 (화면에서만 빠짐)

### 4. 단축어 동작 "가사 추적 시작" (실험 포함)
- App Intent **"가사 추적 시작"** 추가, `AppShortcutsProvider`로 단축어 앱에 노출 (기존 `ResumeLyricsIntent`처럼 숨기지 않음)
- 먼저 **앱을 화면에 띄우지 않고**(`openAppWhenRun = false`) 실행:
  - 이미 추적 중이면 아무것도 안 함 (`ℹ️ 이미 추적 중`)
  - 아니면 2번 이어받기 또는 새 Live Activity 시작 → 위치 추적·폴링 시작
  - "사용자가 정지함" 상태여도 단축어로 실행하면 시작하고 그 상태를 해제 (사용자가 명시적으로 실행한 것이므로)
- **확인할 실험 포인트**: 백그라운드에서 `Activity.request`가 되는지, 위치 추적이 켜지는지. 실패하면 오류를 로그에 남기고 보고서 "질문"에 결과를 적을 것. 실패 시 대안(앱을 잠깐 여는 방식)은 계획 쪽 결정 후 진행
- 로그: `⚡️ 단축어로 실행 — 앱 상태: …` / 결과

## 사용자가 아이폰에서 확인할 것
1. **자동 시작**: 앱 완전히 종료(앱 전환기에서 위로 밀기) → 다시 열기 → 버튼 누르지 않아도 카드가 뜨는지
2. **정지 유지**: [정지] → 앱 종료 → 다시 열기 → 자동 시작되지 않는지 → [시작] 누르면 시작
3. **카드 이어받기**: 추적 중 → 앱을 앱 전환기에서 위로 밀어 종료 → 잠금화면 카드가 남아 있으면 ▶︎ → 가사가 다시 이어지는지
4. **화면**: 메인에 로그가 없고, 맨 아래 [개발자 메뉴]에서 로그·[전체 복사]가 되는지
5. **단축어**:
   - 단축어 앱 → 자동화 → ＋ → **앱** → Spotify 선택, **"열 때"** 체크 → **"즉시 실행"** → 다음 → 동작으로 LiveLyrics의 **"가사 추적 시작"**
   - [정지] 후 앱 종료 → Spotify 열기 → 잠금화면에 카드가 뜨는지, 가사가 나오는지
   - 안 되면 [개발자 메뉴] 로그에서 `⚡️ 단축어로 실행` 줄과 그 아래 결과를 전달
