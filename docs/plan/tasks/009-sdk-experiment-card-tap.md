# 009 — Spotify iOS SDK 연결 실험 + 카드 탭으로 Spotify 열기

상태: 완료

> 작성: Claude 앱 (계획 담당) · Xcode Agent는 **읽기만**
> 작성일: 2026-10-27 · 로드맵 P7

## 목적
1. **SDK 실험**: Web API는 폴링 간격만큼 늦고(재생 중 3초) 호출 한도가 있다. Spotify iOS SDK(App Remote)는 아이폰 안의 Spotify 앱에서 재생 상태 변화를 **즉시** 받고 호출 한도가 없다. 다만 일시정지 약 30초 뒤 연결이 끊기고, 다시 붙으려면 Spotify 앱이 화면에 나와야 한다고 알려져 있다(커뮤니티 보고).
   → **우리 앱 환경(잠금 상태 + 위치 추적으로 살아 있음)에서 SDK가 쓸 만한지**를 확인한다. 이번엔 **기존 Web API 흐름을 대체하지 않고 옆에 붙여서 기록만** 한다.
2. **카드 탭 → Spotify 열기**: ▶︎로 해결되지 않는 "Spotify 앱이 연결을 끊음(404, 기기 없음)" 경우를 위해, 카드의 ▶︎ 외 부분을 누르면 Spotify 앱이 열리게 한다 (Dynamic Lyrics와 같은 방식). Spotify가 열리면 기존 단축어 자동화로 우리 추적도 살아난다.

## 할 일

### A. SDK 연결 실험 (개발자 메뉴 스위치로만 켜짐)
1. **SDK 추가**: 공식 저장소 `spotify/ios-sdk`의 `SpotifyiOS` 프레임워크. 가능한 추가 방법(패키지 관리자/프레임워크 파일)을 확인하고, Xcode에서 사용자가 클릭해야 하는 단계가 있으면 보고서에 **클릭 경로까지** 적는다
2. **설정**
   - Info.plist `LSApplicationQueriesSchemes`에 `spotify`
   - 로그인 scope에 `app-remote-control` 추가 → 기존 `needsRelogin` 흐름으로 재로그인 안내
   - SDK 연결에는 **기존 PKCE 액세스 토큰**을 사용 (연결 직전 `validAccessToken()`으로 갱신). `authorizeAndPlayURI` 등 **Spotify 앱으로 화면을 전환하는 인증은 자동으로 호출하지 않는다** (필요하면 개발자 메뉴 버튼으로만)
3. **새 파일** `SpotifyRemoteService.swift` (앱 타깃): 연결·끊김·재연결 관리, `playerState` 구독
4. **연결 시도 시점**: 스위치가 켜져 있고 추적 중일 때 — 앱이 화면에 올 때, 단축어 실행 때(= Spotify가 막 열렸을 때), ▶︎ 처리 때, Web API가 재생 중을 확인했는데 SDK가 끊겨 있을 때(최대 1분에 1번)
5. **기록만 한다** (카드·가사·폴링 흐름은 지금 그대로 Web API 기준)
   - `🛰 SDK 연결됨` / `🛰 SDK 끊김 (이유) — 마지막 이벤트 후 N초` / `🛰 SDK 연결 실패 (이유)`
   - `🛰 SDK 이벤트: 곡 변경 / 재생 / 일시정지 / 위치 M:SS` (앱 상태·잠금 여부 포함)
   - **비교용**: SDK 이벤트 뒤 Web API가 같은 변화를 알아챈 시각과의 차이를 `🛰 Web API보다 N초 빠름`으로
6. 개발자 메뉴: **"SDK 연결 실험" 스위치(기본 꺼짐)**, 현재 연결 상태, 마지막 이벤트 시각

### B. 카드 탭 → Spotify 열기
1. 앱 URL 스킴 등록 (예: `livelyrics://`) — 현재 Info.plist에 URL Types 없음
2. 잠금화면 카드 전체에 `widgetURL(livelyrics://open-spotify)`. **▶︎ 버튼은 지금처럼 `Button(intent:)` 우선** (버튼 영역 탭은 인텐트, 나머지는 URL)
3. 앱이 `open-spotify`를 받으면 `spotify:`를 열어 Spotify 앱으로 전환. Spotify가 설치돼 있지 않으면 로그만
4. 로그: `🔗 카드 탭 → Spotify 열기`
- 카드 탭은 iOS 규칙상 **잠금 해제가 필요**하다 (▶︎는 잠금 해제 없이 동작하는 것과 다름)

## 사용자가 아이폰에서 확인할 것 (최소)
준비: 재로그인 → 개발자 메뉴 "SDK 연결 실험" 켜기 → Spotify 재생 → 홈 화면 → 화면 잠금
1. **잠금 상태에서 즉시 반응하는지**: 잠금화면의 Spotify 컨트롤로 **다음 곡** 1번, **일시정지 → 재생** 1번 → 그 뒤 개발자 메뉴 로그에서 `🛰` 줄 확인 (연결 유지 여부, "Web API보다 N초 빠름")
2. **카드 탭**: 잠금화면 카드의 ▶︎가 아닌 부분 탭 → 잠금 해제 후 Spotify가 열리는지
- 로그는 `🛰` 줄만 복사해서 주면 됨
