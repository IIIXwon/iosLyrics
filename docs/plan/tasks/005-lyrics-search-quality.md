# 005 — 가사 검색 다듬기 (재검색 간격 · 다시 찾기 · 못 찾은 곡 기록 · 연주곡 제목 판단)

상태: 완료

> 작성: Claude 앱 (계획 담당) · Xcode Agent는 **읽기만**
> 작성일: 2026-10-26 · 로드맵 P3

## 목적
1. 같은 곡을 들을 때마다 LRCLIB을 반복 검색하는 낭비를 없앤다
2. 잘못 저장된 가사를 사용자가 바로잡을 수 있게 한다
3. 실사용에서 가사를 못 찾은 곡을 모아, 나중에 검색 규칙을 보강할 근거를 만든다
4. 제목만 봐도 연주곡인 곡은 검색하지 않는다

## 할 일

### 1. 제목으로 연주곡 판단 (검색 생략)
- Spotify 곡 제목이 아래에 해당하면 **LRCLIB 검색 없이 바로 `instrumental`** 처리 (대소문자 무시)
  - 어디에 있든: `instrumental` (단어 단위)
  - 괄호·대괄호 안이거나 ` - ` 뒤에 올 때만: `inst`, `inst.`, `mr`
    - 예: `Love Dive (Inst.)`, `Song - Instrumental`, `노래 [MR]` → 연주곡
    - 예: `Mr. Brightside`, `Instinct` → 해당 없음 (오탐 방지)
- 로그: `🎼 연주곡 (제목으로 판단): 제목`
- 카드 표시는 기존 연주곡과 같음 ("🎼 연주곡")

### 2. 재검색 간격
- 검색 결과와 **마지막 검색 시각**을 곡별로 기록 (`Application Support/LiveLyrics/` 안, 예: `search-log.json`)
- 다음에 같은 곡을 재생하면:

| 지난 결과 | 다시 검색하는 조건 |
|---|---|
| 싱크 가사 | 하지 않음 (저장본 사용, 기존과 같음) |
| 일반 가사만 | 마지막 검색 후 **24시간** 지났을 때만 (그 전에는 `plain/` 저장본 사용) |
| 못 찾음 | **24시간** 지났을 때만 |
| 연주곡 (LRCLIB 표시) | **30일** 지났을 때만 |
| 연주곡 (제목 판단) | 기록·재검색 불필요 (항상 1번 규칙으로 처리) |

- 간격 안이라 검색을 건너뛸 때 로그: `⏭ 가사 검색 생략 — 못 찾음 기록 (3시간 전)`
- 네트워크 오류로 검색 자체가 실패한 경우는 기록하지 않음 (다음 재생 때 다시 시도)

### 3. 가사 다시 찾기 · 삭제
- 앱 화면 "현재 재생" 구역에 **[가사 다시 찾기]** 버튼
  - 현재 곡의 저장본(`synced/`·`plain/`)과 검색 기록을 지우고 **즉시 다시 검색** → 카드 갱신
  - 제목 판단 연주곡이면 버튼 비활성 (또는 "제목으로 연주곡 판단됨" 표시)
- "저장된 가사" 목록에서 **밀어서 삭제** (파일과 검색 기록 함께 삭제)

### 4. 못 찾은 곡 기록
- "저장된 가사" 화면에 구역 추가: **"못 찾은 곡 (N)"**, 기존 "일반 가사만 있는 곡"과 나란히
- 항목마다: `아티스트 - 제목`, 앨범, 곡 길이, 마지막 검색 시각, **시도한 단계까지의 결과 요약** (예: `1~4단계 결과 없음` / `2단계 후보 3개 — 길이 차이 10초 초과`)
- 목록 아래 **[목록 복사]** 버튼: 못 찾은 곡과 일반 가사만 있는 곡 전체를 텍스트로 복사 (계획 쪽 분석용)
- 다시 찾아서 싱크 가사를 찾으면 목록에서 자동으로 빠짐

## 하지 말 것
- 검색 단계(4단계)·제목 정리 규칙(`TitleCleaner`)·길이 허용 범위(10초)는 **바꾸지 말 것** — 실사용 기록을 본 뒤 별도 지시서로 다룸
- LRCLIB 외 가사 출처 추가 금지, 업로드 기능 금지 (`docs/plan/constraints.md`)
- 카드 갱신·백그라운드 로직 변경 금지
- `docs/plan/`, `CLAUDE.md` 수정 금지

## 사용자가 아이폰에서 확인할 것
1. **제목 연주곡**: 제목에 `(Inst.)`나 `Instrumental`이 붙은 곡 재생 → 로그에 `🎼 연주곡 (제목으로 판단)`, 카드 "🎼 연주곡"
2. **재검색 생략**: 가사를 못 찾는 곡을 재생 → 다음 곡 → 다시 그 곡 재생 → 로그에 `⏭ 가사 검색 생략`
3. **다시 찾기**: 아무 곡에서 [가사 다시 찾기] → 로그에 새 검색 기록, 카드 갱신
4. **삭제**: 저장된 가사 목록에서 한 곡 밀어서 삭제 → 그 곡 다시 재생하면 새로 검색
5. **못 찾은 곡 목록**: 몇 곡 들은 뒤 "못 찾은 곡"에 쌓이는지, [목록 복사]가 되는지
6. 이후 1~2주 평소처럼 사용 → [목록 복사] 결과를 Claude 앱에 전달 (검색 규칙 보강용)
