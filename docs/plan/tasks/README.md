# 작업 지시서

> 작성: Claude 앱 (계획 담당) · Xcode Agent는 **읽기만**

Claude 앱이 Xcode Agent에게 넘기는 작업 지시서를 모아 두는 곳.

## 작업 흐름

```
① Claude 앱   지시서 작성: docs/plan/tasks/NNN-제목.md (상태: 대기)
      ↓ 사용자 → Xcode: "다음 작업 진행해"
② Agent       지시서대로 작업 → BuildProject
③ Agent       보고서 작성: docs/dev/reports/NNN-report.md (상태: 검토 요청)
      ↓ 사용자 → 아이폰 테스트 → Claude 앱: "NNN 검토해줘" + 로그
④ Claude 앱   검토
              ├ 수정 필요 → 지시서 맨 아래 "검토 N차 — 수정 요청" 추가 (상태: 수정 요청) → ②
              └ 통과 → 상태: 완료, docs/plan/roadmap.md·decisions.md 갱신
⑤ Claude 앱   다음 지시서 작성 → ②
```

## 지시서 규칙
- 파일 이름: `001-짧은-영문-제목.md`, `002-…` 순서
- 맨 위 `상태:` 줄 하나: `대기` / `수정 요청` / `완료` / `보류`
- 구성: 목적 / 할 일 / 주의 / 하지 말 것 / 완료 조건 / 사용자가 아이폰에서 확인할 것
- 수정 요청은 지시서를 새로 만들지 않고 **같은 파일 맨 아래에 "검토 N차" 섹션을 추가**

## 보고서 규칙 (Agent가 `docs/dev/reports/`에 작성)
- 파일 이름: 지시서와 같은 번호 `NNN-report.md`
- 맨 위 `상태:` 줄: `진행 중` / `검토 요청`
- 구성: 바꾼 파일과 이유 / 빌드 결과 / 지시서와 다르게 한 점과 이유 / 사용자가 테스트할 항목 / 질문
- 수정 요청을 반영하면 같은 보고서 맨 아래에 "수정 N차" 섹션을 추가
