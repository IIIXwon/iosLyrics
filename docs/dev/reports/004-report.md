## 바뀐 화면 구성 (글로 설명)
**맨 위 "준비 상태" 구역** (Form의 첫 구역, Spotify 구역보다 위)
- 전부 ✅이면 `✅ 준비 완료` 한 줄만 보인다. 누르면 펼쳐져서 4개 항목(Spotify 로그인 · 위치 서비스 · 위치 권한 · 실시간 현황)이 ✅와 짧은 설명("로그인됨", "켜짐", "앱 사용 중")으로 보인다.
- 하나라도 ❌이면 제목이 `⚠️ 준비가 덜 됐어요 (N개)`(주황색)로 바뀌고 **자동으로 펼쳐진다.** ❌ 항목이 ✅ 항목보다 위에 오고, 항목마다 이유(빨간 글씨) · 설정 경로 안내(회색) · 해결 버튼이 보인다.

| 항목 | ❌일 때 문구 | 버튼 |
|---|---|---|
| Spotify 로그인 | "SpotifyConfig.swift에 Client ID를 넣어 주세요"(버튼 없음) / "로그인이 필요해요" / "권한이 추가돼서 다시 로그인해야 해요" | "Spotify로 로그인" / "로그아웃 후 다시 로그인" |
| 위치 서비스 | "아이폰의 위치 서비스가 꺼져 있어요" + "설정 → 개인정보 보호 및 보안 → 위치 서비스" | "설정 열기" |
| 위치 권한 | 미정: "위치 권한을 허용해 주세요" / 거부·제한: "꺼져 있으면 잠금화면 가사가 몇 초 뒤 멈춰요" + "설정 → 이 앱 → 위치 → '앱을 사용하는 동안'" | 미정: "권한 요청" / 거부: "설정 열기" |
| 실시간 현황 | "꺼져 있으면 잠금화면 카드가 뜨지 않아요" + "설정 → 이 앱 → 실시간 현황" | "설정 열기" |

- "앱 사용 중"과 "항상" 모두 ✅로 본다. "항상 허용"은 요구하지 않는다. 정확한 위치 여부는 확인하지 않는다.
- "설정 열기"는 `UIApplication.openSettingsURLString`을 연다.

**그 밖의 화면 변화**
- "잠금화면 추적 시작" 버튼 아래: ❌가 있고 추적 중이 아닐 때만 주황색 `준비 상태를 먼저 확인해 주세요` 한 줄. 버튼은 막지 않는다 (`start()`의 기존 확인 로직 그대로).
- **제거**: 기존 "위치 권한" 구역과 "위치 '항상 허용' 요청" 버튼. `LocationKeepAlive.requestAlways()` 함수는 남겨 뒀다.
- **정리**: Spotify 구역의 "새 권한이 필요해요…" 주황색 안내와 "Client ID를 먼저 넣어 주세요" 빨간 안내를 지웠다 (준비 상태가 대신 보여 줌). 로그인·로그아웃 버튼은 그대로.

## 자동 갱신
다음 때 다시 확인한다.
- 앱이 화면으로 돌아올 때 (`scenePhase == .active`)
- 위치 권한이 바뀔 때 (`locationManagerDidChangeAuthorization` → 새 콜백 `onAuthorizationChange`)
- 실시간 현황이 바뀔 때 (`ActivityAuthorizationInfo().activityEnablementUpdates`)
- Spotify 로그인·로그아웃 직후

## 로그
준비 상태가 **바뀔 때만** 한 줄: `🧭 준비 상태: 위치 권한 ❌ → ✅`. 앱을 처음 켤 때의 최초 상태는 로그로 남기지 않는다.

## 지시서와 다르게 한 점과 이유
- 없음. 아래는 구현 중 판단한 세부 사항이다.
  - **위치 서비스(기기 전체) 확인은 메인 스레드를 막을 수 있어서** 백그라운드에서 실행한다. 그래서 앱을 켠 직후 한순간은 "켜짐"으로 가정하고 표시한 뒤 곧 실제 값으로 바뀐다. 위치 서비스가 꺼진 기기에서는 화면이 잠깐 ✅였다가 ❌로 바뀔 수 있다.
  - **다시 로그인 버튼은 먼저 로그아웃한다.** 권한이 추가된 경우 새 권한을 받으려면 로그아웃이 필요해서, 추적 중이라면 추적도 같이 정지된다 (기존 로그아웃 버튼과 같은 동작).
  - 처음 실행 때 권한 창을 자동으로 띄우지 않는다. 다만 기존 `start()`는 위치 권한이 "미정"이면 여전히 요청 창을 띄운다 (지시서의 "기존 `start()` 확인 로직 유지"를 따름).

## 사용자가 아이폰에서 확인할 것 (지시서와 같음)
1. 평소 상태: 맨 위에 "✅ 준비 완료" 한 줄만 보이는지
2. **실시간 현황 끄기**: 설정 → LiveLyricsExperiment → 실시간 현황 끄기 → 앱으로 돌아오면 ❌로 바뀌고 [설정 열기]로 바로 가는지 → 다시 켜고 돌아오면 ✅
3. **위치 권한 끄기**: 설정 → 앱 → 위치 → "안 함" → 앱 복귀 시 ❌ → [설정 열기]로 "앱을 사용하는 동안"으로 되돌리면 ✅
4. (선택) 위치 서비스 전체 끄기 → ❌와 경로 안내가 맞는지 (iOS 버전에 따라 "설정 → 개인정보 보호 및 보안 → 위치 서비스" 이름이 다를 수 있음) → 다시 켜기
5. 화면이 이전보다 복잡해지지 않았는지 (위치 권한 구역이 사라졌는지)
- 로그에서 볼 줄: `🧭 준비 상태: … ❌ → ✅`

## 수정 메모 (2026-10-26, 사용자 테스트 중 발견)

- **문제**: "위치 서비스" 항목의 [설정 열기] 버튼이 **이 앱의 설정 화면**(`UIApplication.openSettingsURLString`)으로 가는데, 안내 문구는 "설정 → 개인정보 보호 및 보안 → 위치 서비스"(아이폰 전체 설정)라서 서로 맞지 않았다. 앱은 아이폰 전체의 위치 서비스 화면으로 바로 갈 수 없다.
- **수정**: 위치 서비스 항목에서 **[설정 열기] 버튼을 제거**하고, 직접 찾아가는 경로만 안내한다 — "아이폰 설정 앱 → 개인정보 보호 및 보안 → 위치 서비스 → 맨 위 '위치 서비스'를 켜 주세요 (이 앱의 설정 화면이 아니라 아이폰 전체 설정이에요)". 위치 권한·실시간 현황 항목의 [설정 열기]는 이 앱의 설정 화면이 맞아서 그대로 둔다.
- **지시서와 다른 점**: 지시서 표는 위치 서비스 항목의 버튼을 "설정 열기 + 경로 안내"로 정했지만, 위 이유로 버튼은 빼고 경로 안내만 남겼다. 계획 쪽에서 판단해 주세요.
