## 테스트 기록

### 재생 중일 때만 위치 추적
- 재생을 멈추고 3분(`idleGrace`)이 지나면 위치 추적이 꺼지고, 재생 재개 시 다시 켜지는 동작 — 이상 없음

### 2단계 (개선 1 이전)
- Spotify 앱과 시간 차이 1~3초, **항상 카드가 늦음** → 원인: 카드가 3초마다 찍힌 시간을 정지 표시 → 개선 1로 해결
- 곡 변경·일시정지·seek 반영 1~3초 (폴링 3초 때문, 예상 범위)

### 1초 폴링 (개선 1 이후)
- 88분 동안 조회 4,428회 (평균 약 1.19초에 1회), **호출 한도 초과 없음**
- 배터리 약 3% 소모 (시간당 약 2%) — 3초 간격과 거의 차이 없음 → 1초 간격 확정
- 로그의 `💓 조회 #N`은 10회마다 한 줄이라 숫자가 10 단위로 보임 (정상)

### 3단계 가사
- 한 번 `-1011` 오류가 났다가 재시도 없이 다시 하니 정상 (일시적 서버 문제로 추정) → 이후 재시도 로직 추가
